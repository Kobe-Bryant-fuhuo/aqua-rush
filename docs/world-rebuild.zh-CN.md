# 三个水上世界重建

> 本文记录首轮重建；后续技巧连段、尾流超车与横渡机关的当前规则及验证见 [驾驶选择与技巧连段](gameplay-optimization.zh-CN.md)。

原先五张地图已从本地和联机目录移除。现在三个世界都支持快速比赛、计时赛和 2–4 人房间，使用全新的路线与建筑布置。保留三圈、每圈十二个有方向的检查点。界面沿用原版街机设计系统。

## 设计与实际操作

| 世界 | 核心驾驶段落 | 操作与退路 |
| --- | --- | --- |
| 断潮坝 / Breakwater | 泄洪跳台、低堤墙、第二段侧向跳台、阶梯岩岸和高架 | 对齐橙色跳台，带速度起跳，落水得到短暂增压；低速或错过跳台时，从发光箭头标出的外侧水路绕过堤墙 |
| 霓虹沉城 / Nightfall | 被淹没的建筑街区、三组周期闸门、地铁跳台 | 提前观察闸门顶灯和开口，保持中线或争取更宽的窗口；闸门始终留有可通过的中心开口 |
| 失落环礁 / Sunken Temple | 沉水巨石拱门、断裂柱廊、遗迹堤墙和旋流水路 | 飞越堤墙或走外侧；后半圈可以切入水纹，利用有方向的水流出弯 |

跳台是真实倾斜支撑面。船越过台沿后进入有重力的空中运动，保留较弱的转向能力。水面落地只发放一次短增压。飞行高度参与堤墙和船只碰撞；船在空中不会继续生成水面尾流。

岸边建筑有碰撞。普通岸线布置同时避开中心水路与跳台落点范围；刻意放在路上的低墙保留明显的绕行线。引导线表示建议路线，不是隐形围墙，检查点以外的开阔水域仍然可以驾驶。

## 界面

- 标题页直接预览真实赛场；选图时即时切换世界。
- 选择赛道与开始比赛是两个清楚的动作，便于比较地图。
- 比赛界面保留原版名次、圈数、计时和增压读数，增加小地图与下一个检查点提示。
- 起跳显示滞空时间；临近跳台、闸门和水流时显示相应提示。
- 手机采用可滚动的赛道卡片、触摸方向盘与独立增压按钮；暂停和静音保留原版触控尺寸。
- 配色沿用奶油白、亮黄、珊瑚红、青色和深蓝；标题、按钮、卡片、暂停和结算使用原有粗斜体、切角和强调色规范。新增详情面板和小地图复用同一组颜色变量。

- [WaterRace](https://github.com/swisspol/WaterRace)：水上竞速开源参考。未引入其代码或媒体。

## 同步与记录

`WorldMechanics` 提供共享的跳台、建筑和闸门数据。闸门相位由模拟时间计算，服务器和预测端使用相同规则；减少动态效果只改变视觉，不改变水流、波浪或闸门判定。

协议提升为 v4，快照包含飞行状态、垂直速度、滞空计时、落地冷却和增压计时。客户端预测同时处理世界碰撞；船与船的最终结果仍由服务器决定。前端与 Worker 必须一起部署。

旧五图记录按原 ID 和规则版本保留在存档区，新图成绩从空白开始。音量和减少动态效果设置保留；旧成绩不能出现在新图排行榜中。

## 检查与边界

- `map-browser.spec.ts`：从真实菜单进入三个世界，用键盘输入完成全部 36 个检查点，不使用传送、强制过点或自动救援。
- `redesign-browser.spec.ts`：桌面与手机菜单、世界预览，以及从起点驾驶至跳台的实际起跳截图。
- `world-mechanics.spec.ts`：起跳、空中状态回放、一次性落地奖励、重置状态；闸门中心始终可通行，闸块有碰撞且允许从足够高处越过。
- `world-online-race.spec.ts`：固定步长下四个输入驾驶员完成每个世界的服务器物理比赛。
- `online-prediction.spec.ts`：50/100/200ms 延迟与受控抖动下的预测修正，包含跳台前起步场景。
- 真实 WebSocket 整场比赛、浏览器联机、视觉回归和 1080p 正式构建性能使用独立检查。

这些检查证明比赛可完成、规则与画面能够对应，不证明每位玩家都觉得好玩。手机验证使用 Chromium 设备模拟；没有把桌面 GPU 的帧率当作真实手机帧率。没有职业模式、武器、特技按键或公开匹配。

### 2026-09-08 验证结果

- 完整默认套件：144 通过，60 跳过；跳过的是重复的纯规则平台矩阵、仅桌面的场景，以及独立执行的正式构建性能检查。
- 最后一次水流位置调整后的受影响套件：65 通过，25 个重复平台场景跳过，包含桌面/手机完整三圈、AI、四人服务器物理、预测、绕行、起跳和视觉回归。
- Cloudflare 本地集成：24 通过，8 个平台重复或独立选择项跳过。三张图都通过四个真实 WebSocket 客户端的完整三圈与再开一局。
- 延迟 WebSocket 渲染专项另行执行：1 个和 3 个对手两项均通过，测量窗口内没有对手移动帧停滞。
- 计时对照：沿环礁同一条旋流水路驾驶，有水流约 7.00 秒，无水流约 7.43 秒，均无碰撞。该数字表示局部路线收益，不是整圈保证。
- `npm run build`、`npm run cf:check`、`git diff --check` 通过。
