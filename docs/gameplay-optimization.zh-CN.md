# 驾驶选择与技巧连段

这一轮围绕设计包中的“操作主题、可选择的风险、成功后兑现优势”展开。原版 UI 的配色、字体、切角按钮和面板保留；地图数量保持三张。

## 现在怎样玩

### 漂移释放与连段

弯中按住 Space（手机增压键）并转向，蓄力达到 I / II / III 档后松开。释放同时提供短增压和燃料补充。空中不积累漂移，快速点按不能刷奖励。

漂亮漂移、精准落水、取奖励门和尾流超车可以连接起来。连段十秒内有效，最高三段；第二、第三段分别增加燃料补充，并把增压速度上限从 33 提升到 35、37 世界单位/秒。普通航行上限仍为 25。明显碰撞会打断连段，超时也会失去额外速度。

被动回充从每秒 12% 降至 4%，玩家需要决定什么时候花掉增压、什么时候通过驾驶把它赚回来。AI 同样消耗增压，按性格选择漂移、直线增压和横渡绕行。

### 跟船、蓄满、拉出

在同向移动对手后方保持一小段距离，持续跟住约 1.25 秒，屏幕显示 `PULL OUT!`。此时侧移离开尾流，会获得一次超车短增压和燃料补充，随后有四秒冷却。

仅仅贴着对手不会持续发奖励；静止、反向、已完赛和离场选手不能提供尾流。单人计时赛自然不出现跟船机制。

### 起跳与落水选择

起跳前可以用漂移释放攒足速度。空中保留微调，落水前把船头摆正并收小转向；对齐落水的奖励更强，并能继续连段。大角度横着落水会损失速度。

### 霓虹城的横渡窗口

原来始终留出中线的闸门已替换为作业船横切。每个机关按固定模拟时间经历开放、黄色预警、横渡、清空四个阶段，提前信号和船体碰撞使用同一份状态。

中线可能被挡住，右侧标出的水道始终可通行。中线出口布置能量门：判断到达时间正确，可以取门接增压；不确定时走右侧。机关不会因玩家靠近而临时针对玩家改变时机。

## 三图的驾驶段落

| 地图 | 练习与连续选择 |
| --- | --- |
| 断潮坝 | 首弯漂移门 → 松键起跳 → 精准落水 → 出口取能量；后半圈再组合峡湾漂移、第二跳台和终盘漂移 |
| 霓虹沉城 | 读预警、判断中线窗口或右侧绕行；利用前车尾流补充超车机会；地铁段将漂移接到跳台 |
| 失落环礁 | 遗迹入弯漂移与飞跃；后半圈在旋流线取能量、反打漂移出弯，稳妥路线可以放弃奖励 |

每张图都有五处独立结算的奖励门。成功只能在每船每圈领取一次，失误与恢复不能重复领取。

## 实际输入计时对照

以下由同一固定步长驾驶器从相同起始速度和燃料出发，使用真实船控、波浪、碰撞与交互规则。没有直接修改比赛时间、位置或奖励；“技巧跑法”选择漂移区并在落水时对齐船头。数字描述这些输入策略，不代表所有人的收益，也不是真人满意度数据。

| 段落 | 跑法 | 时间 | 接触次数 |
| --- | --- | ---: | ---: |
| 断潮坝首段 | 普通驾驶、起跳和取门 | 12.42s | 0 |
| 同一首段 | 漂移释放、起跳、精准落水连成三段 | 11.75s | 0 |
| 断潮坝一圈 | 普通驾驶 | 48.05s | 0 |
| 同一圈 | 选择漂移段、使用赚到的增压 | 47.65s | 0 |
| 首个横渡段 | 右侧稳妥线 | 5.28s | 0 |
| 同一横渡段 | 正确窗口走中线、取出口能量 | 4.92s | 0 |
| 同一横渡段 | 错误窗口强走中线 | 6.75s | 1 |

首段连贯操作净省约 0.67 秒。整圈并不是“所有弯都漂移就更快”：过早释放、错误漂移和落水方向会抵消收益。横渡的收益与失败代价形成了明确取舍。

## 验证

完整默认套件 166 项通过、78 个重复平台或独立性能场景跳过；首个漂移门最终调整后，相关套件另有 39 项通过、23 个重复平台场景跳过。Cloudflare 集成 26 项通过、6 个重复平台场景跳过，最终断潮坝调整后再次完成四客户端整场复验。三张图的正式构建性能场景已独立执行并通过。

- 技巧释放、点按防刷、空中不充漂移、三段上限和超时、碰撞打断、尾流方向/速度/高度约束、离开尾流才兑现，以及状态恢复重放均有规则测试。
- 尾流在 0/100/200ms RTT 下完成蓄力和超车奖励，预测修正 P95 小于 2 世界单位；离场对手的旧速度不能产生虚假尾流。
- 桌面和手机模拟器中通过键盘从起点驾驶，确认连段显示、横渡提示及原版 UI 颜色变量。
- 三图均通过自然三圈驾驶、三名 AI 完赛和四人权威物理比赛。真实四 WebSocket 客户端分别完成三图并再次开局；断线重连与 1/3 对手延迟渲染也已检查。
- 1080p 正式构建在 RTX 5060 Laptop 上三图约 165 FPS，P95 帧耗时 6.2ms，资源预算通过。未用这项结果代替真实手机性能测试。

本轮协议为 v5，快照包含连段、尾流和离场状态。前端与 Worker 同步部署。三图计时规则版本升至 2，之前的 PB 归档，设置保留。

功能与计时可以自动验证；长期耐玩程度仍需要真实玩家反复试玩。没有新增武器、随机必死机关、付费道具或强制评分任务。
